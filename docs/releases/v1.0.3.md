## English

### What's changed

- **Finder in the app picker:** Finder is now discovered from its system location, so you can assign it a hotkey without locating it manually.
- **Reuse existing Finder windows:** a hotkey activates the running Finder directly, preserving its existing windows instead of sending a reopen request that could create another window. Other apps retain their usual open/reopen behavior.
- **Shortcut setup guidance:** the Finder shortcut editor now explains how to free up `⌥⌘Space` from the macOS Finder search shortcut.

### Use ⌥⌘Space for Finder

1. Open **System Settings → Keyboard → Keyboard Shortcuts → Spotlight**, then turn off **Show Finder search window**.
2. Open QuickLaunch, click **Add (+)**, select **Finder**, and record **⌥⌘Space**.
3. Save. If the shortcut shows ⚠️, restart QuickLaunch or edit and save it after disabling the system shortcut.

For minimized Finder windows, enable **Restore minimized windows** and allow QuickLaunch under **Privacy & Security → Accessibility**. If no folder windows are open, Finder's desktop is activated; use **⌘N** to open a new window. Switching to a window on another Space follows your macOS Mission Control settings.

### Install or update

Download **QuickLaunch.dmg** from **Assets** below. Quit the running QuickLaunch, open the DMG, and drag QuickLaunch into **Applications**, replacing the previous version. Then launch QuickLaunch again. Requires macOS 14 or later.

## 한국어

### 변경 사항

- **Finder 목록 표시:** 시스템 폴더에 있는 Finder를 자동으로 인식하여, 직접 경로를 찾지 않고 단축키를 지정할 수 있습니다.
- **기존 Finder 창 사용:** 단축키를 누르면 실행 중인 Finder를 바로 활성화합니다. 새 창이 생길 수 있는 다시 열기 요청을 보내지 않아 기존 창이 유지됩니다. 다른 앱의 열기 동작은 기존과 같습니다.
- **단축키 설정 안내:** Finder를 선택하면 macOS의 기본 Finder 검색 단축키를 해제하고 `⌥⌘Space`를 지정하는 방법을 안내합니다.

### ⌥⌘Space로 Finder 사용하기

1. **시스템 설정 → 키보드 → 키보드 단축키 → Spotlight**에서 **Finder 검색 윈도우 보기**를 끄세요.
2. QuickLaunch에서 **추가(+) → Finder**를 선택하고 **⌥⌘Space**를 입력하세요.
3. 저장하세요. ⚠️가 표시되면 시스템 단축키를 해제한 뒤 QuickLaunch를 재시작하거나 단축키를 편집·저장하세요.

최소화된 Finder 창도 복원하려면 **최소화된 창 복원**을 켜고 **개인정보 보호 및 보안 → 손쉬운 사용**에서 QuickLaunch를 허용하세요. 열린 폴더 창이 없으면 Finder의 데스크탑이 활성화되며, **⌘N**으로 새 창을 열 수 있습니다. 다른 Space의 창으로 전환하는 동작은 macOS Mission Control 설정을 따릅니다.

### 설치 또는 업데이트

아래 **Assets**에서 **QuickLaunch.dmg**를 받으세요. 실행 중인 QuickLaunch를 종료한 뒤 DMG를 열고, QuickLaunch를 **Applications**로 드래그하여 기존 버전을 교체하세요. 이후 QuickLaunch를 다시 실행하면 됩니다. macOS 14 이상이 필요합니다.
